Select the environment you want to use:
1. Idira Secrets Manager, SaaS
2. Idira Secrets Manager, Self-Hosted

Enter a number between 1 and 3: 2


  Initialize the Idira Secrets Manager CLI with Idira Secrets Manager, Self-Hosted or Conjur OSS
.


  The init command creates a configuration file (.conjurrc) that contains the details for connec
ting to Idira Secrets
  Manager. This file is located under the user's root directory.


  USAGE

    conjur init self-hosted [--flags]

  FLAGS

    -a --account      Idira Secrets Manager organization account name
    -t --authn-type   Authentication type to use (e.g. LDAP, OIDC, JWT)
    -c --ca-cert      Idira Secrets Manager SSL certificate (will be obtained from host unless p
rovided by this option)
    --cert-file       File to write the server's certificate to (/root/conjur-server.pem)
    -f --file         File to write the configuration to. You must set the CONJURRC environment
variable to the same value for this file to be used for further commands. (/root/.conjurrc)
    --force           Force overwrite of existing configuration file
    --force-netrc     Use a file-based credential storage rather than OS-native keystore (for co
mpatibility with Summon)
    -i --insecure     Allow non-HTTPS connections (insecure)
    --jwt-file        Path to the JWT file if using authn-jwt
    --jwt-host-id     Host ID for authn-jwt (not required if JWT contains host ID)
    -s --self-signed  Allow self-signed certificates (insecure)
    --service-id      Service ID if using alternative authentication type
    -u --url          Url of the Idira Secrets Manager service. Will prompt if omitted.
